# Ser, estar и hay
> Ser — что это такое, estar — где и в каком состоянии, hay — есть ли это вообще.

## Спряжение estar
| Местоимение | estar |
| --- | --- |
| yo | **estoy** |
| tú | **estás** |
| él / ella / usted | **está** |
| nosotros | **estamos** |
| vosotros | **estáis** |
| ellos / ellas / ustedes | **están** |

## Когда используется estar
1. Местонахождение: **Madrid está en España.** — Мадрид находится в Испании. **¿Dónde estás?** — Где ты?
2. Состояние, настроение, самочувствие: **Estoy cansado.** — Я устал. **Está enfadada.** — Она злится.
3. Результат действия: **La puerta está abierta.** — Дверь открыта.
4. *bien / mal*: **Estoy bien.** — У меня всё хорошо.
5. Действие в процессе (**estar + герундий**): **Estoy comiendo.** — Я сейчас ем.

## Ser или estar: главная идея
- **ser** — что предмет из себя представляет, постоянная характеристика.
- **estar** — как он сейчас и где он.

- **Ana es guapa.** — Аня красивая (вообще).
- **Ana está guapa hoy.** — Аня сегодня хорошо выглядит.
- **El café es caro.** — Кофе дорогой (по природе).
- **El café está frío.** — Кофе остыл.

## Прилагательные, которые меняют смысл
| ser | estar |
| --- | --- |
| **ser listo** — быть умным | **estar listo** — быть готовым |
| **ser aburrido** — быть скучным | **estar aburrido** — скучать |
| **ser malo** — быть плохим | **estar malo** — болеть |
| **ser rico** — быть богатым | **estar rico** — быть вкусным |
| **ser verde** — быть зелёным | **estar verde** — быть незрелым |

- **La paella está muy rica.** — Паэлья очень вкусная.
- **¿Estás listo?** — Ты готов?

## Hay — «есть, имеется»
**Hay** — одна форма для единственного и множественного числа. Оно сообщает, что что-то существует или где-то находится, когда предмет новый для собеседника.

- **Hay un banco cerca.** — Рядом есть банк.
- **Hay dos cafés en esta calle.** — На этой улице два кафе.
- **¿Hay leche?** — Молоко есть?
- **No hay problema.** — Нет проблем.

После *hay* идут: **un/una/unos/unas**, числа, *mucho, poco, algún*, или существительное без артикля.

## Hay или está
- **hay** — есть ли *какой-то* предмет: **Hay una farmacia en la plaza.** — На площади есть аптека.
- **está / están** — где *конкретный, известный* предмет: **La farmacia está en la plaza.** — Аптека (та самая) на площади.

> 💡 Правило: после *hay* не ставят *el/la/los/las*. Если хочется сказать «el», нужен *estar*.

## Сводная таблица
| Вопрос | Глагол | Пример |
| --- | --- | --- |
| Кто / что это? | ser | **Es mi madre.** |
| Откуда? | ser de | **Somos de Kazán.** |
| Где (конкретный)? | estar | **Mi madre está en casa.** |
| Как себя чувствуешь? | estar | **Estoy muy bien.** |
| Есть ли? | hay | **Hay un hotel aquí.** |
| Где событие? | ser | **El concierto es en el estadio.** |

## Типичные ошибки
- ✗ *Soy bien* → **Estoy bien.**
- ✗ *Hay el museo* → **El museo está aquí.** или **Hay un museo aquí.**
- ✗ *Han muchos turistas* → **Hay muchos turistas.**
- ✗ *Soy cansado* → **Estoy cansado.**
- ✗ *Está médico* → **Es médico.** — профессия всегда с *ser*.
