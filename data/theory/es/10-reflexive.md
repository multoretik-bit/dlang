# Возвратные глаголы
> Испанское «se» — почти русское «-ся», только оно меняется по лицам и стоит перед глаголом.

## Как они устроены
В словаре возвратный глагол пишется с **-se** на конце: **lavarse** — мыться, **llamarse** — называться. При спряжении *se* превращается в местоимение нужного лица и встаёт **перед** глаголом.

| Лицо | levantarse — вставать |
| --- | --- |
| yo | **me** levanto |
| tú | **te** levantas |
| él / ella / usted | **se** levanta |
| nosotros | **nos** levantamos |
| vosotros | **os** levantáis |
| ellos / ustedes | **se** levantan |

- **Me llamo Olga.** — Меня зовут Ольга.
- **¿A qué hora te levantas?** — Во сколько ты встаёшь?
- **Nos vemos mañana.** — Увидимся завтра.

## Где стоит местоимение
Перед спрягаемым глаголом: **Me ducho por la mañana.** При отрицании *no* идёт перед местоимением: **No me acuerdo.** — Я не помню.

С инфинитивом или герундием — два варианта: перед всей конструкцией или слитно в конце.
- **Me voy a duchar.** = **Voy a ducharme.** — Я пойду в душ.
- **Te estás durmiendo.** = **Estás durmiéndote.** — Ты засыпаешь.

## Распорядок дня
- **despertarse** (e → ie) — просыпаться: **Me despierto a las siete.**
- **levantarse** — вставать
- **ducharse** — принимать душ
- **lavarse los dientes** — чистить зубы
- **vestirse** (e → i) — одеваться: **Me visto rápido.**
- **peinarse** — причёсываться
- **acostarse** (o → ue) — ложиться спать: **Me acuesto tarde.**
- **sentarse** (e → ie) — садиться: **Siéntate.** — Садись.

## Смысл меняется
Иногда *se* меняет значение глагола:

| Без se | С se |
| --- | --- |
| **ir** — идти | **irse** — уходить: **Me voy.** — Я ухожу. |
| **dormir** — спать | **dormirse** — засыпать |
| **llamar** — звать, звонить | **llamarse** — называться |
| **quedar** — договориться встретиться | **quedarse** — оставаться |
| **poner** — класть | **ponerse** — надевать; становиться |
| **acordar** — договориться | **acordarse de** — помнить |

## Не совпадает с русским
Возвратность в двух языках часто не совпадает. Проверяйте каждый глагол.
- **учиться** — **estudiar** / **aprender** (без *se*!): **Estudio español.**
- **бояться** — **tener miedo**
- **нравиться** — **gustar** (другая конструкция)
- **жениться / выйти замуж** — **casarse** (с *se*!): **Se casan en junio.**
- **забыть** — **olvidar** или **olvidarse de**
- **смеяться** — **reírse**: **Nos reímos mucho.**

## Взаимное действие
Во множественном числе *se, nos, os* могут значить «друг друга»:
- **Nos queremos.** — Мы любим друг друга.
- **Se escriben cada día.** — Они пишут друг другу каждый день.

## Части тела — с артиклем
- **Me lavo las manos.** — Я мою руки. (Не ✗ *mis manos*.)
- **Se rompió la pierna.** — Он сломал ногу.

## Типичные ошибки
- ✗ *Yo levanto a las siete* → **Me levanto a las siete.** (*levanto* без *me* — «поднимаю что-то»).
- ✗ *Me estudio* → **Estudio.**
- ✗ *Voy a me duchar* → **Me voy a duchar** или **Voy a ducharme.**
- ✗ *Se llamo* → **Me llamo** — местоимение меняется по лицам.
