# Полезные конструкции и похожие слова
@group Сложные конструкции

| Конструкция | Смысл | Пример |
| --- | --- | --- |
| used to + V1 | Раньше было регулярно, сейчас изменилось | I used to live in a village. — Раньше я жил в деревне. |
| be used to + существительное / V-ing | Привык | I'm used to the heat. — Я привык к жаре. |
| get used to + существительное / V-ing | Привыкать | I'm getting used to speaking English. — Я привыкаю говорить по-английски. |
| would like + to / существительное | Хотел бы (вежливо) | I'd like to book a room. — Я хотел бы забронировать номер. |
| It takes + время + to | Занимает время | It takes two hours to edit it. — На монтаж уходит два часа. |
| spend + время + V-ing | Тратить время на действие | I spend two hours editing. |
| too… to / enough to | Слишком… чтобы / достаточно… чтобы | It's too far to walk. — Слишком далеко, чтобы идти пешком. |

| Пара | Как различать |
| --- | --- |
| make / do | make a video, make a decision, make a mistake — создать / получить результат; do homework, do exercise, do the dishes — выполнить занятие. Учить сочетания. |
| say / tell | say something; tell someone something |
| speak / talk | speak English — владеть языком; talk to someone — разговаривать с кем-то |
| look / see / watch | look at — направить взгляд; see — увидеть; watch — наблюдать процесс |
| borrow / lend | borrow from — взять взаймы; lend to — дать взаймы |

❗ **Did you use to…? / I didn't use to…** — после did начальная форма use.

**Практика:** «Я привык работать дома».

+++ Проверить себя
**I'm used to working at home.** Это привычность сейчас, не used to work.
