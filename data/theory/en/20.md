# Условные предложения: if / unless
@group Сложные конструкции

| Тип | Схема | Смысл и пример |
| --- | --- | --- |
| Zero | if + Present Simple → Present Simple | Общая закономерность: If you heat ice, it melts. — Если нагревать лёд, он тает. |
| First | if + Present Simple → will + V1 | Реальное будущее: If it rains, I'll stay home. — Если пойдёт дождь, останусь дома. |
| Second | if + Past Simple → would + V1 | Воображаемое сейчас / в будущем: If I had more time, I would travel more. — Если бы было больше времени, путешествовал бы чаще. |
| Third — следующий шаг | if + had + V3 → would have + V3 | Несбывшееся прошлое: If I had known, I would have helped. — Если бы я знал, я бы помог. |

- **If I were you, I would…** — На твоём месте я бы…
- **Unless = if… not:** I won't go unless you come with me. — Я не пойду, если ты не пойдёшь со мной.
- Условие можно ставить в конце: **I'll stay home if it rains.** Если if-часть первая, обычно ставим запятую.

❗ В обычном First Conditional: **If it rains**, не If it will rain.

**Практика:** «Если у меня будет время, я тебе помогу».

**If I have time, I'll help you.**
