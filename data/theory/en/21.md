# Passive Voice — пассивный залог
@group Сложные конструкции

> 💡 

**Пассив** нужен, когда важен объект действия, а исполнитель неизвестен или не в центре внимания. **Объект + be в нужном времени + V3**.

| Время | Формула | Пример |
| --- | --- | --- |
| Present Simple | am / is / are + V3 | English is spoken here. — Здесь говорят по-английски. |
| Past Simple | was / were + V3 | The video was uploaded yesterday. — Видео загрузили вчера. |
| Future | will be + V3 | The room will be cleaned tomorrow. — Комнату уберут завтра. |
| Present Perfect | have / has been + V3 | The work has been finished. — Работа закончена. |
| С модальным | can / must + be + V3 | It can be fixed. — Это можно исправить. |

- **Someone stole my phone → My phone was stolen.** Кто-то украл мой телефон → Мой телефон украли.
- Исполнитель: **The book was written by Orwell.** — Книга написана Оруэллом.
- Вопрос / отрицание через be: **Was it sent? It wasn't sent.**

❗ Меняется **be**, а V3 остаётся: is made / was made / will be made.

**Практика:** «Этот дом построили в 2000 году».

+++ Проверить себя
**This house was built in 2000.**
