# Прилагательные, сравнения, наречия
@group Слова и связи между ними

| Конструкция | Правило / пример | Перевод |
| --- | --- | --- |
| Короткое прилагательное | small → smaller → the smallest | маленький → меньше → самый маленький |
| Длинное | expensive → more expensive → the most expensive | дорогой → дороже → самый дорогой |
| На -y | happy → happier → the happiest | счастливый → счастливее → самый счастливый |
| Исключения | good → better → the best; bad → worse → the worst | хороший / плохой |
| Равенство | as cheap as; not as cheap as | такой же дешёвый; не такой дешёвый |
| Избыток | too expensive | слишком дорого |
| Достаточность | good enough; enough time | достаточно хороший; достаточно времени |
| Усиление | so expensive; such an expensive hotel | так дорого; такой дорогой отель |

- **This room is cheaper than that one.** — Эта комната дешевле той.
- Прилагательное описывает предмет: **a careful driver**. Наречие — действие: **He drives carefully**.
- Часто **-ly**: slow → slowly. Исключения: good → well; fast → fast; hard → hard. **Hardly** = едва, почти не.
- После be / seem / feel часто прилагательное: **I feel tired**, не tiredly.

❗ Не **more better**, а **better**. Не **enough cheap**, а **cheap enough**.

**Практика:** «Этот отель слишком дорогой».

**This hotel is too expensive.**
