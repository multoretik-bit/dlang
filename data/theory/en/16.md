# Количество: some / any, much / many, few / little
@group Слова и связи между ними

| Слово | С чем / когда | Пример |
| --- | --- | --- |
| some | Обычно утверждения; предложения / просьбы | I have some money. Would you like some tea? |
| any | Обычно вопросы / отрицания; также «любой» | Do you have any questions? Choose any seat. |
| many | Исчисляемые во множественном | many books — много книг |
| much | Неисчисляемые | much time — много времени |
| a lot of / lots of | Оба типа | a lot of people / water |
| a few / a little | Немного, но есть | a few friends / a little money |
| few / little | Мало, почти нет | few friends / little money |
| no | Ни одного / никакого | There is no milk. — Молока нет. |

- **Somebody / anybody / nobody** работают похоже: **I didn't see anybody / I saw nobody.**
- **Each / every + ед. число:** every day, each person. **Both** — оба; **either** — любой из двух; **neither** — ни один из двух.

❗ **I have a few friends** — у меня есть несколько друзей; **I have few friends** — друзей мало. Разница в оценке количества.

**Практика:** How … people are here? I don't have … time.

+++ Проверить себя
**many; much** (во втором также возможно **any**, если времени совсем нет).
