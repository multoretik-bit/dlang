# There is / are, have / have got
@group Основа английского

| Конструкция | Смысл | Пример |
| --- | --- | --- |
| there is + ед. / неисчисляемое | Где-то есть что-то | There is a desk in my room. — В моей комнате есть стол. |
| there are + мн. число | Где-то есть несколько | There are two windows. — Есть два окна. |
| there was / were | Где-то было | There were many people. — Было много людей. |
| have / has | Кто-то имеет | I have a camera. She has a car. |
| have got / has got | Иметь (часто разговорный британский) | I've got a camera. She's got a car. |

- **Is there a shop nearby?** — Рядом есть магазин? **There isn't any milk.** — Молока нет.
- **Do you have a car? / I don't have a car.**
- **Have you got a car? / I haven't got a car.** Не смешивай две схемы.
- **There is a phone on the table** — вводим наличие; **The phone is on the table** — сообщаем место известного телефона.

❗ Для действий have используем обычную схему: **I have breakfast at eight. Do you have breakfast?**

**Практика:** «В квартире две спальни».

+++ Проверить себя
**There are two bedrooms in the apartment.**
