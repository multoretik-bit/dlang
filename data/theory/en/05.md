# Существительные: число, исчисляемость, принадлежность
@group Основа английского

| Правило | Примеры |
| --- | --- |
| Обычно +s | book → books |
| После s / sh / ch / x часто +es | bus → buses; watch → watches |
| Согласная + y → ies | city → cities; но boy → boys |
| Часть слов на f / fe → ves | wife → wives; но roof → roofs |
| Исключения | man → men; woman → women; child → children; person → people; foot → feet; tooth → teeth; mouse → mice |
| Одинаковая форма | sheep → sheep; fish → fish (обычно) |

- **Countable:** a chair, two chairs — можно посчитать отдельные штуки.
- **Uncountable:** water, money, information, advice, furniture, luggage. Обычно без a/an и без окончания множественного числа.
- Считай единицы: **a bottle of water; two pieces of advice** — бутылка воды; два совета.
- Принадлежность: **Sveta's phone** — телефон Светы; **my parents' house** — дом моих родителей; **the children's room** — комната детей.

❗ **Some information**, не an information; **advice**, не advices.

**Практика:** «два совета», «три ребёнка».
