# Фразовые глаголы — полезный минимум
@group Сложные конструкции

**⚠️ Фразовый глагол** — глагол с частицей / предлогом, сочетание часто имеет отдельный смысл. Учи в короткой фразе.

| Глагол | Перевод | Пример |
| --- | --- | --- |
| wake up / get up | проснуться / встать | I wake up at seven and get up at eight. |
| turn on / turn off | включить / выключить | Turn off the light. |
| put on / take off | надеть / снять | Take off your shoes. |
| find out | выяснить | I'll find out tomorrow. |
| look for / look after | искать / присматривать | I'm looking for my keys. |
| give up | бросить, сдаться | Don't give up. |
| carry on | продолжать | Carry on working. |
| come back / go out | вернуться / выйти куда-то | I'll come back soon. |
| pick up | подобрать / забрать | Can you pick me up at six? |
| set up | настроить / организовать | I need to set up the camera. |
| check in / check out | зарегистрироваться / выписаться | What time do we check out? |
| run out of | исчерпать запас | We've run out of water. |
| look forward to + V-ing | ждать с радостью | I look forward to seeing you. |

- Разделяемые: **turn off the light / turn the light off**. С местоимением обязательно **turn it off**.
- Неразделяемые: **look after him**, не look him after. Разделяемость учится вместе с глаголом.

❗ Значение зависит от контекста: **take off** также «взлететь», **pick up** — не только «поднять».

**Практика:** замени the camera на it: Turn on the camera.
