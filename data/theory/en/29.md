# Словообразование: как узнавать новые слова
@group Глаголы, произношение и словарь

| Элемент | Что делает | Пример |
| --- | --- | --- |
| un- / in- / im- / dis- | Часто отрицание | happy → unhappy; possible → impossible; agree → disagree |
| re- | Повтор | write → rewrite — переписать |
| -er / -or | Человек по занятию | teach → teacher; act → actor |
| -tion / -ment | Часто существительное | inform → information; develop → development |
| -ness | Состояние / качество | happy → happiness |
| -ful / -less | С качеством / без него | careful / careless |
| -able | Возможность / свойство | readable — читаемый, понятный |
| -ly | Часто наречие | quick → quickly; но friendly — прилагательное |

- **Семейство:** create → creation → creative → creatively — создавать → создание → творческий → творчески.
- Приставку нельзя свободно ставить к любому слову: **unhappy**, но **impossible**. Проверяй существующее слово.
- Запоминай сочетания: **make a decision, take a break, pay attention, spend time**.

❗ Знать перевод отдельного слова недостаточно: учи **значение + произношение + короткий пример**.

**Практика:** образуй «счастье» от happy и «быстро» от quick.
